# Posters / editorial layout

**Composition**: one dominant focal element (huge type or a single image), everything
else subordinate. Grid can be broken deliberately in the focal area while margins/base
rhythm stay disciplined everywhere else — asymmetric hero, on-grid support.

**Type as image**: at poster scale, type itself is the graphic — push scale contrast far
beyond UI ratios (one dominant headline size vs. disciplined small body/caption text),
use type weight and spacing as compositional elements, not just for reading.

**Print-specific**: define bleed (typically 3mm/0.125in) and safe margin separately from
the visual canvas; check CMYK-safe color choices for anything actually printed (avoid
pure saturated RGB blues/greens that shift badly in print).

**Anti-patterns**: default PowerPoint gradients, clip-art, centered-everything with no
tension, text crammed to the edge with no margin discipline, more than one competing
focal point.

philosophy expressed as a museum-poster composition, rendered via a Python drawing
script and visually confirmed (no overlaps, clean margins).
