# Presentation / slide design

**One idea per slide**: a slide title states the single takeaway as a sentence, not a
label ("Revenue grew 3x in Q3" not "Revenue"). Supporting visual (one chart, one
diagram, or 3 short bullets max) — never a wall of bullet text.

**Grid**: 16:9 canvas, consistent margin (e.g. 64–80px) and a fixed content-safe area
across every slide so elements don't jump between slides. Title always same position/
size across the deck.

**Type**: 2 sizes per slide max (title + body) beyond a small caption/footer size.
Body text large enough to read from the back of a room (≥24px equivalent at 1920px
canvas width).

**Anti-patterns**: default template gradient background, clip-art icons, more than 3
bullet levels of nested indentation, dense paragraph text, a different layout
grid per slide with no consistency.

**Verified build**: `presentation-demo/slide.html` at 1920×1080 — single takeaway
headline, one supporting stat block, consistent margin system, rendered and confirmed.
