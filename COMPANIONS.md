# Companion skills (not bundled)

Design Mastery works alone. These optional skills add depth but have their own licences, so
install them from their authors rather than from this repo:

- taste-skill, redesign-skill, image-to-code-skill, gpt-tasteskill (Leonxlnx "taste-skill" family)
- the "designer-skills" plugin (design-research, visual-critique, interaction-design, design-systems, ux-strategy, prototyping-testing)
- impeccable, dataviz, brand-guidelines (Anthropic skills set: github.com/anthropics/skills)

Check each project's licence before use. Bundled here under Apache-2.0 (licence files
included): frontend-design, canvas-design, theme-factory, web-artifacts-builder,
webapp-testing, algorithmic-art. Fonts in canvas-design/canvas-fonts are SIL OFL 1.1 (licence file beside each).
