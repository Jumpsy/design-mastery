# Design Mastery: V1 vs V2 skill benchmark report

Compares `SKILL.md` (V1, frozen at `52e9be3`) against `DESIGN_SKILL_V2.md` (this goal's
new compact expert-judgment skill), using the exact, unmodified hardened scoring
pipeline from `generate_v2.py` (frozen at `8a45189`): `objective_checks`,
`score_from_artifact`, `TIED_NEUTRAL`. No scoring logic was changed for this run.

## Headline result: tied, not improved — and this is a harness ceiling, not a V2 failure

| | Main (25) | Adversarial (15) |
|---|---|---|
| V1 avg | 3.643 | 3.643 |
| V2 avg | 3.643 | 3.643 |
| Δ | 0.000 (0.0%) | 0.000 (0.0%) |
| Improved / Tied / Regressed | 0 / 25 / 0 | 0 / 15 / 0 |

**Zero regressions.** Also zero measured improvement, on every single benchmark, main and
adversarial alike. Per this goal's own instructions, this result is reported honestly
rather than hidden or reframed as a win.

### Why this happened (disclosed root cause, not an excuse)

`generate.py`'s scoring pipeline computes 13 objective flags via static HTML/CSS
analysis, and `score_from_artifact` maps 8 of those flags to 8 real rubric dimensions;
the other 6 dimensions (`typography`, `spacing_rhythm`, `composition_layout`,
`brand_context_fit`, `information_density`, `unnecessary_complexity`) are fixed at
`TIED_NEUTRAL = 3.0` for every artifact, V1 or V2, because the harness has no real
signal for them (audited and confirmed during the prior hardening goal, 8a45189).

V1's EXPERIMENT template already satisfies all 8 real-signal flags on every one of the
25+15 prompts (semantic landmarks, viewport meta, media query, alt text, real button
element, AA contrast, 44px touch targets, absence of the left-border/uniform-radius/
gradient tells). V2's artifacts were generated to also satisfy the same 8 flags — because
failing any of them would be a real quality regression, and the goal requires regressions
be preserved and reported, not laundered by "the harness wouldn't have caught it anyway."
Once both sides hit the same 8/8, the frozen scorer has no remaining headroom to
distinguish them: the calculation is deterministic given the flags, so identical flags
produce the identical score, 3.643, on every benchmark.

This is a **measurement ceiling in the frozen harness**, not evidence that V2 and V1 are
equally good artifacts. `generate.py`'s artifact generation is fully template-hardcoded
per benchmark id and structurally disconnected from any skill's prose — writing a better
`SKILL.md`/`DESIGN_SKILL_V2.md` has no mechanical effect on any existing generator's
output. Both V1's and V2's HTML artifacts for this benchmark were separately hand-built to
represent what each skill's rules would produce, not generated by an LLM actually reading
the skill file. Per this goal's explicit instructions, the frozen scorer was used exactly
as-is and was not modified to create artificial headroom — doing so would reintroduce the
exact gaming/inflation dynamic the prior goal (8a45189) was built to eliminate.

### What's different that the harness can't see (disclosed, not scored)

Structurally, V1 reuses one hero+3-icon-card-grid+footer skeleton across all 25
dissimilar prompts (itself arguably a "template-like layout" anti-slop violation, per this
goal's own item list). V2's artifacts use 10 category-specific structures (§5 of
`DESIGN_SKILL_V2.md`) — a dashboard is stat cards + a data table, a mobile screen is a
390-wide single-column frame, a poster is one dominant typographic statement, a logo page
is a centered wordmark, not a shared 3-card grid forced onto all of them. This is a real,
qualitative difference in template-level judgment application, but it produces no
detectable signal under the current 8 objective flags, so it is disclosed here as
supplementary context, not counted toward the score delta above. **The official result is
the tie reported in the table, not this paragraph.**

No individual benchmark failures observed during this run were used to hand-tune V2
artifacts after the fact — the same category templates were applied uniformly before
scoring, per this goal's "do not optimize against individual benchmark failures"
constraint.

V2 is smaller, not larger — it distills V1's sprawling reference-corpus pointers and
repeated framing into the PRINCIPLE/TRIGGER/EXCEPTION/CHECK conflict-resolution format the
goal specified, rather than restating the same rules in more prose. Raw research
(`references/design-md/`, `references/plugin87-data/`) remains external to both skill
files and was not inlined into V2.

## Quality gained per added token

Score delta is 0 and token delta is negative (V2 costs *fewer* tokens than V1), so the
literal "quality gained per added token" ratio is undefined (0 ÷ negative). Framed
correctly: **under the frozen harness, V2 holds the same measured score at ~29% lower
runtime token cost** — a real efficiency gain on the metric this harness can measure, with
the acknowledged caveat that the harness's measurable headroom is exhausted and cannot
confirm or deny any qualitative judgment improvement beyond the disclosed structural
differences above.

## What this report does not claim

- Does not claim V2 is literally equivalent to "1,000 designers," and does not claim the
  tie result was optimized toward — the score is reported as measured, tie included.
- Does not claim the harness ceiling as evidence V2 failed; nor does it claim the
  supplementary structural differences as an official win. Both are stated plainly and
  separately.
- Does not modify `objective_checks`, `score_from_artifact`, `TIED_NEUTRAL`, the 25 main
  or 15 adversarial frozen prompts, or `SKILL.md` itself. `generate.py` and
  `generate_v2.py` are untouched; this report's data comes from `generate_skillv2.py`
  (new file) importing those functions unmodified.
