Zero-loss webhook dispatch for engineering teams who don't want to build an event bus.

Drop HookRail into your database transaction. We guarantee at-least-once signed delivery, handle exponential backoff retries with jitter, enforce consumer rate-limits, and route webhooks straight to localhost during development.

TRANSACTION OUTBOX DISPATCH 
import { HookRail } from '@hookrail/sdk';

const hookrail = new HookRail({ apiKey: process.env.HOOKRAIL_SECRET });

// Atomically enqueue inside your DB transaction (zero dual-write loss):
await hookrail.events.publish({
  topic: 'order.fulfilled',
  idempotencyKey: 'evt_ord_9942a1',
  payload: {
    orderId: 'ord_9942',
    customer: 'alex@acme.corp',
    amountCents: 48500,
    currency: 'USD'
  },
  signature: { algorithm: 'HMAC_SHA256' },
  retryPolicy: { maxAttempts: 5, backoff: 'exponential' }
});
