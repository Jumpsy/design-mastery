# Design Mastery V1 — Benchmark Report V2 (hardened harness)

Skill frozen at `52e9be3`, unmodified in this pass. This is a rescoring of
the **same artifacts** from the V1 benchmark run, using a corrected
evaluator. Artifact generation was not touched — only the scoring pipeline.
Original V1 results are preserved unmodified at `results_v1.json` /
`aggregate_v1.json` / `BENCHMARK_REPORT_V1.md` for historical comparison.

## Source of the previous inflation (audit finding)

`generate.py`'s `score_from_flags(o, is_experiment)` took `is_experiment` —
a boolean literally stating which condition the artifact belonged to — as a
**direct scoring input**, not just as a metadata label. Concretely, 8 of the
15 rubric dimensions (`visual_hierarchy`, `clarity`, `composition_layout`,
`typography`, `spacing_rhythm`, `consistency`, `brand_context_fit`,
`unnecessary_complexity`) were hardcoded constants keyed **only** on that
boolean:

```python
dims["visual_hierarchy"] = 4.2 if is_experiment else 2.8
dims["typography"] = 4.1 if is_experiment else 2.7
...
```

The scorer did not need to inspect the HTML at all to assign those 8
scores — it looked at the label and returned a fixed number. This is a
textbook identity leak: it guarantees EXPERIMENT wins those dimensions
every single time, regardless of what was actually generated, and it is
exactly the mechanism the V1 report's own limitations section flagged
(`overall_task_effectiveness = 2.71 → 4.11`, +51.7%) without yet fixing.

Two smaller compounding issues also found in the audit:
- `accessibility` had a bug where `contrast_passes_wcag_aa is None` also
  mapped to 4.5 (same as "passes"), silently treating "not measured" as
  "measured good."
- `originality_antislop` used only the gradient-hero flag, ignoring the
  `left_border_accent_strip_tell` flag that was computed but never used in
  scoring — a partially-wired signal.

No evidence was found of unequal retries, unequal token/iteration budgets,
or unequal verification passes between CONTROL and EXPERIMENT — both were
generated by one template pass each, with no repair loop on either side.
That part of the harness was already fair and required no fix.

## Fixes made

`generate_v2.py` (new file, imports `generate.py` for artifact generation
only — no artifact content changed):

1. **New scorer `score_from_artifact(html, o)` takes no label/identity
   argument at all.** Its signature makes the leak structurally impossible:
   there is nothing to swap. The same function, byte-for-byte, is called on
   control artifacts, experiment artifacts, and synthetic calibration
   fixtures.
2. **Every dimension is either backed by a real signal or explicitly tied.**
   8 dimensions now derive from actual objective_checks() flags
   (`usability`, `interaction_clarity`, `accessibility`, `responsiveness`,
   `clarity`, `visual_hierarchy`, `consistency`, `originality_antislop`).
   The 6 dimensions this harness has no real static-analysis signal for
   (`typography`, `spacing_rhythm`, `composition_layout`,
   `brand_context_fit`, `information_density`, `unnecessary_complexity`) are
   now a **fixed tied constant (3.0)** for both conditions, instead of a
   fabricated winner. This directly satisfies "do not convert implementation
   differences into quality points unless they genuinely affect the
   user-facing result" — this harness cannot verify those 6 dimensions
   affect the user-facing result at all, so it no longer scores them.
3. **`accessibility` "unmeasured" no longer scores as "passes."** It's now
   3.0 (neutral) when contrast couldn't be parsed, 4.5 when it demonstrably
   passes AA, 2.0 when it demonstrably fails.
4. **`originality_antislop` now uses both wired anti-slop tells**
   (gradient + left-border-strip), partial credit if only one is present.
5. **A/B blinding**: the scorer never receives control/experiment identity.
   Swap-label and duplicate-output calibration tests (below) confirm this
   structurally, not just empirically.
6. **Objective vs. subjective separation**: rubric dims are now themselves
   deterministic reductions of the objective checks — there is no separate
   hidden "subjective judgment" layer left in the harness to leak through.
7. Confirmed equal treatment already existed for prompts, generation budget
   (one template pass, no retries), and rendering environment — documented
   here rather than re-engineered, since there was nothing to fix.

## Calibration results

Full machine output: `calibration_v2.json`. All 6 checks passed; the full
suite was gated on this (`generate_v2.py` refuses to rescore if any
calibration check fails).

| Check | Result | Detail |
|---|---|---|
| Identical-output test | **PASS** | same artifact scored twice → byte-identical scores |
| Swapped-label test | **PASS** | scorer has no label parameter; relabeling A↔B cannot change output by construction |
| Duplicate-output test | **PASS** | same artifact in both slots → delta = 0.0 |
| Worse-EXPERIMENT fixture | **PASS** | an experiment-styled fixture with injected real failures (gradient hero, div-onclick fake button, missing alt, no viewport) scored lower than a normal experiment artifact — confirms the scorer will penalize EXPERIMENT-styled output when it's actually broken |
| Better-CONTROL fixture | **PASS** | a control-styled fixture with real structural wins (semantic tags, real button, alt text, media query, no gradient) scored higher than a normal control artifact — confirms the scorer rewards real quality regardless of visual idiom |
| Repeatability (5 reruns × 6-sample subset) | **PASS (variance = 0)** | harness is a deterministic function of static HTML with no live model/render call on either side, so true variance is exactly 0 — see limitations below, this is disclosed as a real constraint on what this harness can detect, not evidence of stability under real generation variance |

Improved / tied / regressed (main suite, `overall_task_effectiveness`,
±0.001 tolerance): **25 improved, 0 tied, 0 regressed.**

95% CI on the paired per-benchmark delta: **[0.879, 0.879]** — the interval
collapses to a point because, as the repeatability test shows, this harness
is fully deterministic (fixed templates, regex scoring, no sampling
variance anywhere), not because the true effect is known to that precision.
**The tight interval is a property of the measurement instrument, not of
design quality in general — do not read it as high real-world confidence.**

Compare to V1's uncorrected headline: control_avg 2.71 → experiment_avg
4.11 (+51.7%). The corrected delta (+31.8%) is **materially smaller** once
the 8 label-hardcoded dimensions are replaced with real-signal-or-tied
scoring — roughly a 38% reduction in the reported effect size. The
remaining delta traces entirely to the 8 dimensions with real objective
backing (see by-dimension table); it is not zero, but it is honest about
what's actually measured.

### By category

**Still flat across all 10 categories** (2.764 → 3.643 identically in every
category) — same root cause as V1: one fixed CONTROL template and one fixed
EXPERIMENT template are applied regardless of prompt category, so this
harness has zero power to detect category-specific effects. **This was not
fixed in this pass** — fixing it requires bespoke per-category artifact
generation, which is out of scope here (this goal fixes the *scoring*
pipeline, not the *generation* methodology) and is the top recommendation
for a V3 harness.

### Adversarial suite

Same 2.764 → 3.643 pattern, 0 regressions, for the same shared-template
reason. The three previously-reported findings in `BENCHMARK_REPORT_V1.md`
(adv-11 accessibility tie, adv-05 untested line-wrap, adv-13 circular
gradient finding) still hold under the corrected scorer — none of those
were scoring-pipeline problems, they were generation-methodology
limitations, unaffected by this fix.

## Remaining evaluator limitations (honest, not resolved by this pass)

1. **Category-blind generation, unchanged.** All 25×2 and 15×2 artifacts
   still come from exactly two fixed templates. This scoring fix cannot
   create category-level signal that was never encoded in the artifacts.
2. **Deterministic harness → 0 measured variance.** The repeatability check
   passing with variance=0 is a fact about this static-template harness,
   not a claim that live model generation is this stable. A V3 harness that
   generates artifacts via live model calls (one call per condition per
   prompt, no extra retries either side) would produce real run-to-run
   variance worth reporting a genuine CI on.
3. **6 of 15 dimensions are now explicitly tied at a neutral constant**
   because no real signal exists for them in this harness. This is more
   honest than v1 (which fabricated a winner for all 6) but it also means
   this report cannot claim anything about typography, spacing, layout
   composition, brand fit, information density, or unnecessary complexity —
   those claims are withdrawn from the corrected report entirely, not
   just "found tied."
4. **This is not independent human/LLM blind judgment.** Because both
   conditions are template-generated and scored by one deterministic
   function written by the same process that built the templates, this is
   not equivalent to a genuinely blinded third-party evaluator looking at
   two rendered pages without knowing which is which — it is the
   structurally-blind equivalent achievable within a static-analysis
   harness. A real blind pass (e.g., an independent LLM call shown only
   two unlabeled screenshots, order randomized) is the recommended next
   step for a V3 harness and was not performed here.
5. **No live rendering was added in this pass either.** Objective checks
   remain regex/contrast-math over generated markup, not headless-browser
   verification (still no `playwright`/`puppeteer` available in this
   environment). Overflow, actual zoom reflow, and console errors remain
   unverified, same limitation as V1.

## Verdict

The previous +51.7% headline was inflated: roughly 38% of the reported
delta traced to 8 rubric dimensions that were hardcoded by condition label
rather than measured from the artifact. After removing that leak and tying
every dimension without a real signal, V1 still shows a genuine, real-signal
delta of +31.8% on the 8 dimensions this harness can actually measure
(semantic HTML, keyboard-accessible controls, responsive breakpoints, alt
text, absence of two named anti-slop tells) — those are real, checkable
wins, not artifacts of the scoring bug. No regressions were found under the
corrected harness either, but per the limitations above, this harness still
cannot detect a regression that a bespoke-per-prompt, blind, live-generated
V3 harness could — the corrected result is more honest, not proof of
robustness.
