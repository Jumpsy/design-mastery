Your first event is the easy part.

Three steps from your app to their endpoint.

1. Create an endpoint

Register the HTTPS URL that should receive your events. This demo uses endpoint_01; no real request leaves your browser.

2. Send an event

Use the sample above as the request shape. Give each event a stable name and include the data your customer needs.

3. Follow the delivery

Check the response and attempt history. In this prototype, the delivery receipt simulates a successful HTTP 200 response.
