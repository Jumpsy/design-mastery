# Live V3 benchmark: plans before implementation

The brief overrides generic reference structures. These are standalone design prototypes, with local interaction and no connected services. Frontend-design supports implementation; the web and product category references guide hierarchy and behavior. No existing benchmark outputs were used as templates.

## web-landing-hero
Reading: developer API landing page for engineers evaluating webhook infrastructure. Native CSS, restrained technical aesthetic; variance 7, motion 3, density 5.
Layout: compact navigation, asymmetric headline and executable sample, a shared delivery strip, then an expandable quickstart.
Signature: code pane continues into a perforated delivery receipt; the CTA sends a clearly labeled local sample through it.
Palette: ice #edf3f9, white #ffffff, navy #142b49, cobalt #224fd2, muted #53667c. IBM Plex Sans Condensed display, IBM Plex Sans body, IBM Plex Mono code. Display 84px; utility/body scale 12.8/16/20/25/31.25px. Spacing 12/20/36/52/76px.
Gate: abstract network artwork would be familiar and uninformative, so it was removed before building. The product action is the visual proof; no gradient, feature cards, decorative pills, shadows, or accent strips. The receipt supplies the memorable moment. Pass, subject to rendered hierarchy.

## web-pricing-recreate
Reading: B2B project accounting pricing for studio owners comparing operating costs. Native CSS, continuous rate sheet; variance 6, motion 2, density 6.
Layout: broad title, explicit billing selector, three open plan columns that align with a semantic comparison table, practical FAQs.
Signature: the citron Studio column runs continuously from its plan header through the comparison rows.
Palette: paper #fafbf7, ink #253128, muted #5d665e, citron #e2ef94, line #d5dbd0. Bricolage Grotesque display, Manrope body. Scale based on 17 × 1.25: 13.6/17/21.25/26.56/33.2/41.5/51.9/64.85px. Custom spacing 7/14/21/35/49/77px, overriding the guide's default 4/8 grid as the user requests.
Gate: separate rounded pricing cards would reproduce a generic three-card grid; removed. Continuous columns support real comparison, annual totals remain visible, and the highlight serves an actual recommendation. Pass, with a known need to verify narrow-screen table scrolling.

## web-waitlist
Reading: consumer AI voice app for people capturing errands and passing thoughts. Native CSS, conversational typographic poster; variance 8, motion 3, density 3.
Layout: asymmetric oversized headline and inline email form; on the right, a voice note with selectively emphasized words resolves into a useful reminder. Small supporting explanation and privacy disclosure follow.
Signature: spoken thought becomes a composed reminder through a typographic transcript.
Palette: coral #ff795f, ink #401e20, pale #fff2e8, muted #552729 (darkened after contrast review). DynaPuff restrained wordmark, DM Sans display and body; body scale 12.8/16/20/25/31.25px, one 88px display exception. Spacing 12/20/36/52/76px.
Gate: a serif/italic cream hero would be category shorthand rather than an identity. Replaced with coral, generous sans lettering, and the product's actual input/output. No blob, glow, phone frame, fake social proof, or endless waveform animation. Pass; verify the typography doesn't overwhelm signup.

## product-settings
Reading: personal settings for a collaborative writing workspace, used occasionally by working adults. Native CSS, calm functional workspace; variance 4, motion 2, density 6.
Layout: slim desktop context rail, settings title, five group rows (notifications, focus, privacy, accessibility, sync), separated danger section, persistent save/undo bar. Mobile becomes a single column.
Signature: changes are accumulated in a persistent status bar with explicit save and undo instead of ambiguous autosaving.
Palette: canvas #f0f2ee, surface #ffffff, ink #27342f, muted #616a65, green #28644b, danger #a52d35. Public Sans body, Newsreader section title (the product is a writing workspace); 12.8/16/20/25/31.25/39.06px. Spacing 12/20/28/44/60px.
Gate: five boxed groups would create nested-card repetition; replaced with fieldsets on one surface. Strong familiarity is intentional for controls. A restrained serif title and clear state feedback supply character without novelizing toggles. Pass; uniqueness will likely score below the marketing pages.
