### 3.1 LLM 友好的段落结构

**目标：** +10 分

**标准：**
- 平均段落长度：50-150 词（中文 50-150 字）
- 单个观点独立成段
- 段落间逻辑清晰
- 使用过渡词连接

**优化前：**
```markdown
SEO 是一个复杂的过程，需要考虑很多因素，包括关键词研究、内容优化、技术优化和外链建设，而且这些因素相互影响，需要系统性地规划和执行，同时还要持续监控和调整，因为搜索引擎的算法在不断更新，竞争对手也在不断优化，所以 SEO 是一个持续的过程，不是一次性工作。
```

**优化后：**
```markdown
SEO 是一个系统性的过程，包含多个关键要素。

首先，**关键词研究**是 SEO 的基础。你需要识别目标受众搜索的关键词，了解搜索意图，并选择有排名潜力的关键词。

其次，**内容优化**是 SEO 的核心。高质量、相关性强的内容能够满足用户需求，提高页面停留时间，降低跳出率。

第三，**技术优化**是 SEO 的前提。网站需要快速加载、移动友好、结构清晰，才能被搜索引擎有效抓取和索引。

最后，**外链建设**提升网站权威性。来自其他高质量网站的链接相当于投票，能够显著提高排名。

需要注意的是，SEO 是一个**持续的过程**，不是一次性工作。搜索引擎算法不断更新，竞争对手持续优化，你需要定期监控表现并调整策略。
```

## 5. 引用密度优化

### 5.1 关键词密度

**目标：** +5 分

**标准：**
- **英文：** 主关键词密度 1-2%
- **中文：** 主关键词密度 2-4%
- **长尾关键词：** 3-5 个，自然分布
- **语义相关词：** 10-15 个

**计算方法：**
```
关键词密度 = (关键词出现次数 / 总词数) × 100%
```

**示例：**
```markdown
文章长度：1,500 词
主关键词："SEO optimization"
目标密度：1.5%
目标出现次数：1,500 × 0.015 = 22-23 次

**分布策略：**
- 标题（H1）：1 次
- 副标题（H2/H3）：3-4 次
- 开头 100 词：2-3 次
- 正文：15-16 次（均匀分布）
- 结尾：1-2 次
```

**自然分布技巧：**
```markdown
1. **使用同义词和变体**
   - SEO optimization
   - Search engine optimization
   - SEO strategy
   - Optimizing for search engines

2. **结合上下文使用**
   ✅ "Effective SEO optimization requires..."
   ✅ "Learn how SEO optimization can improve..."
   ✅ "The key to successful SEO optimization is..."

   ❌ "SEO optimization. SEO optimization. SEO optimization."

3. **不要过度优化**
   如果某个关键词密度超过 3%，考虑使用同义词或删除部分出现。
```

## 6. 技术优化

### 6.1 页面速度优化

**目标：** +3 分

**关键指标：**
- **首次内容绘制（FCP）：** < 1.8 秒
- **最大内容绘制（LCP）：** < 2.5 秒
- **首次输入延迟（FID）：** < 100 毫秒
- **累积布局偏移（CLS）：** < 0.1

**优化建议：**
```markdown
### 图片优化
- 使用现代格式（WebP, AVIF）
- 压缩图片（TinyPNG, ImageOptim）
- 使用响应式图片（srcset）
- 懒加载图片（loading="lazy"）

### 代码优化
- 最小化 CSS 和 JavaScript
- 移除未使用的代码
- 延迟加载非关键 CSS
- 使用 HTTP/2 或 HTTP/3

### 服务器优化
- 使用 CDN（Cloudflare, AWS CloudFront）
- 启用 Gzip 或 Brotli 压缩
- 使用浏览器缓存
- 优化数据库查询
```
